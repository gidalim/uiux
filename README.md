## 7주차 사용자 흐름

### 확인할 문제

실제 이용하는 유저의 흐름에 따라 동작 하도록 인터랙션 시나리오를 설계

### 수정 내용 

- 기존 메인 페이지와 별도로 시작 페이지를 새롭게 설계
- 세션 스토리를 통한 방문 여부를 확인, 처음 서비스를 이용하는 유저에게 시작 페이지 접근을 유도
- 단계별 스포트라이트를 통해 제공하는 서비스의 정보를 전달
- 모바일의 버튼 및 텍스트 비율 수정

### 확인할 기능
- 첫 접속 분기를 체크 ( 시크릿 탭을 통하여 다시 확인 가능)
- 튜토리얼 단계 이동 ( 이전 / 다음을 통한 이동과 스포트라이트 부분을 클릭하는 것으로 이동 )
- 튜토리얼 도중 스포트라이트 이외의 외부 클릭, 스크롤 잠금을 확인
- 튜토리얼 다시보기 기능을 통한 동작 점검
- PC / 모바일 환경(768px)에서 튜토리얼이 올바르게 동작하는 지 확인
