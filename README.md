## 8주차 추가 로직

배포 웹사이트 주소 : https://gidalim.github.io/uiux/
깃허브 주소 : https://github.com/gidalim/uiux

### 확인할 문제

7주차 튜토리얼에 이어서 일정을 등록/삭제하는 로직을 추가

### 수정 내용 

- 주간/월간에 대응하여 일정을 추가 및 삭제하는 로직 추가
  - 일정에 상호 작용시 해당 연/월/일이 출력되며 일정을 확인하고 추가/제거 할 수 있다.

- 내용을 미입력시, 하단에 입력 요청 문구 추가
- 일정이 추가 될 경우 태그 색상으로 일정이 생성된다.

- 중복된 코드를 수정 및 최적화
  - 객체에서 관리하던 색상표를 CSS로 전임했다
  - 캘린더를 그리는 로직을 createCalendarCell 함수로 통일
  - 함수가 복잡해졌기에 용도에 따라 주석으로 묶었다.
  - 박스 디자인을 개선하고 가로 스크롤바가 생성되는 것을 제거

### 확인할 기능
- 일정을 등록하고 삭제해보기
- 빈 공간으로 일정 생성해보기
- 월간 / 주간으로 동기화 되는 지 확인
- PC / 모바일 환경(768px)에서 튜토리얼이 올바르게 동작하는 지 확인
