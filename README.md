### 확인할 문제

9주차 UI폼관련 피드백을 만족하며, 튜토리얼의 흐름을 일정등록까지 연결하기

### 수정 내용 

1. 월간/ 주간 탭과 더불어 일간 탭을 새로이 개설
2. 일정에 기간을 선택할 수 있도록 기능을 추가
3. 중복된 일정을 추가 할 수 없도록 지정, 과도한 입력 방지 기능 추가
4. submit 이벤트를 통한 처리와 성공/실패를 알려주는 토스트를 띄우는 기능을 추가

### 확인할 기능
- 월간/주간/일간 탭전환을 확인
- 일정 등록에서 기간설정을 통해 광역으로 지정가능 
- 일정 등록시 토스트를 통해 일정 생성중 표기
- 일정 등록시, 중복된 이름은 생성불가(disable)처리
- 786px 미만에서 모바일 대응을 확인
