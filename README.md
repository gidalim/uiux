## 6주차 반응형 수정

### 확인할 문제

클릭, 입력, 선택 변경 동작을 구현하기

### 수정 내용 

### 클릭
- Day / Night 모드를 상단의 버튼을 통한 토글로 기능 추가
- 캘린더를 노션 스타일로 7일 단위로 구성
- 월간/주간 캘린더를 탭으로 전환하는 기능 추가
- 모바일의 경우 주간 우선, PC의 경우 월간 우선으로 지정
- CSS를 변수로 지정하여 대응하기 쉽게 작성

### 입력
- 태그에 자동완성 기능을 추가

### 선택 변경 동작 구현 
- 개발자 페이지 제공을 체크박스 확인 절차를 통한 절차로 구현 
- 기능적 구현만 존재


### 확인할 기능
- Day / Night 모드 버튼 토글 확인
- 캘린더의 화살표 버튼 (◀, ▶)을 통한 월간 이동
- 탭을 통한 월간 / 주간 모드 전환
- 768px 이하에서 모바일 모드 대응
- 태그 생성을 통한 자동완성 기능
- 체크박스를 통한 개발자 링크 확인

### 피드백 포인트
- 생성된 태그의 색상의 범위를 제한하여 가시성이 좋은 디자인을 확보 / (태그를 구분하기 쉽게 디자인) 
- 오류 발생 이후 올바른 태그 생성시, 오류 메시지가 나오지 않게 수정 / 추후 토스트나 별도의 기능으로 전환예정
