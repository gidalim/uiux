## 5주차 반응형 수정

### 확인할 문제

폼을 통한 태그 생성을 관리한다.

### 수정 내용 

- 공백 제출시 공백 안내 메시지 출력
- 중복 태그 제출시 안내 메시지 출력
- 태그 생성시 임의의 색상을 가진 태그를 생성 및 안내 메시지 출력
- 태그 생성시 0.5초 버튼 비활성화 기능 추가

### 확인할 기능
태그를 생성을 통한 오류 사항들을 점검


### 피드백 포인트
- 생성된 태그의 색상의 범위를 제한하여 가시성이 좋은 디자인을 확보 (2026/ 10/ 19/ 확인)
- 오류 발생 이후 올바른 태그 생성시, 오류 메시지가 나오지 않게 수정 (2026/ 10/ 19/ 확인)
